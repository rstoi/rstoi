# Pessoas

Torna a **propriedade** visível: quem é dono de qual projeto, decisão ou área. O
worker `weekly-intelligence` usa isto para atribuir compromissos a um responsável.

> **Privacidade.** Apenas o necessário para o trabalho (nome/apelido, papel, do que
> é dono). Sem dados pessoais sensíveis. Arquivo compartilhado.

## Modelo

```
### <Nome ou apelido>
- **Papel:** <cargo/função>
- **Dono de:** <projetos, áreas ou decisões>
- **Canal preferido:** <WhatsApp | e-mail | …>
```

_Preencha com as pessoas do time conforme o harness for adotado._
