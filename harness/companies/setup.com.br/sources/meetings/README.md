# Fontes — reuniões

Inteligência de reuniões: os **compromissos, riscos, dúvidas e decisões** que
raramente chegam a um documento polido. É a principal entrada do worker
`weekly-intelligence`.

## Como usar

- Uma nota por reunião, um arquivo por reunião.
- Nome do arquivo: `AAAA-MM-DD-assunto-curto.md` (data na frente ordena e facilita
  a janela dos "últimos 7 dias").
- Copie `_template-reuniao.md` e preencha. Foque no que muda o estado da empresa —
  não na transcrição inteira.

> **Sem segredos.** Não cole credenciais, tokens ou dados sensíveis aqui. Este é
> um arquivo compartilhado.
