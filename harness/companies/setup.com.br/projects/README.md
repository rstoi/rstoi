# Projetos — estado atual

Um arquivo por projeto, com o **estado atual** (não o histórico completo). O worker
`weekly-intelligence` lê estes arquivos para reportar "movimento por projeto".

Projetos atuais (sistemas internos encapsulados como conectores):

- [`gestao-projetos.md`](gestao-projetos.md)
- [`gestao-contratos.md`](gestao-contratos.md)
- [`comercial.md`](comercial.md)

## Modelo de arquivo de projeto

```
# <Projeto>
- **Dono:** <pessoa / agente>
- **Status atual:** <uma linha>
- **Última atualização:** AAAA-MM-DD

## Em andamento
## Riscos / bloqueios
## Próximos passos
```
