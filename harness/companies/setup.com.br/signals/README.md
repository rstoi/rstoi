# Sinais

Sinais soltos que ainda não são uma decisão nem uma nota de reunião: métricas que
mudaram, alertas, observações de clientes, itens vindos de grupos de WhatsApp
autorizados. Matéria-prima para o brief semanal detectar tendências e riscos
crescentes.

- Um arquivo por lote/semana, ou apêndices curtos datados.
- Nome: `AAAA-MM-DD-sinal.md`.
- **Sem segredos** — arquivo compartilhado.

_Opcional: só crie arquivos aqui quando um sinal real precisar ser preservado._
